Lit Agent Keychain

Getting started

  1. Add a secret. The first save also provisions your vault inside the Chipotle TEE, which takes about 30–60 seconds. Later saves take a few seconds.
  2. Mint an agent key. One credential per runtime agent. It is shown once — copy it into the agent's environment.
  3. Choose who may read what. New secrets are readable by every agent you mint until you edit their policy.
  4. Read it from your agent with the snippet at the bottom of this page.

Secrets

Which agents may read this secret is set after saving, via Edit policy. Until then every agent you mint can read it.

Agents (runtime keys)

Each agent is a scoped Chipotle usage key. It authenticates to this API and runs the reader action. It can only read secrets, never manage them. Names must be unique among active agents.

Setup agents (full access)

Bearer tokens you approved on the Authorize your agent page. Each one can do everything this dashboard can. They do not expire and are not revoked by signing out — revoke them here when the agent is done.

Permitted actions (in-TEE-only tier)

Actions attached here can Lit.Actions.Decrypt any ciphertext in your vault, inside the TEE. Attach only code you've audited.

Use from an agent

Node.js 18+ (also Bun and Deno with npm specifiers). Install the SDK, put the minted key in the agent's environment, then read by name:

npm install @lit-protocol/keychain
export LIT_AGENT_KEYCHAIN_KEY=…   # the key shown once when you minted the agent
// agent.mjs
import { LitAgentKeychain } from '@lit-protocol/keychain';
const keychain = new LitAgentKeychain({ usageApiKey: process.env.LIT_AGENT_KEYCHAIN_KEY, baseUrl: '' });
const value = await keychain.get('OPENAI_API_KEY');
No npm? Download the single-file SDK instead 
curl -fsSL /sdk/lit-agent-keychain.js -o lit-agent-keychain.mjs
# then: import { LitAgentKeychain } from './lit-agent-keychain.mjs';

Deno and browsers can import the URL directly: import { LitAgentKeychain } from '/sdk/lit-agent-keychain.js'. Node's module loader does not load https: imports.
