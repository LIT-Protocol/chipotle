Verify Lit Chipotle

Confirm that the Lit Chipotle API server is running unmodified code inside a genuine Intel TDX enclave operated by Phala Cloud — entirely in your browser, no terminal required. This runs the quick-verify checks: it reads the live attestation, recomputes the configuration hash, confirms the app identity, and queries the on-chain whitelist on Base.

1 Live attestation idle

Fetch /info and /attestation from the running server and read its reported identity and TDX quote.

2 Configuration-hash integrity idle

Recompute SHA-256(app_compose) in your browser and confirm it equals the compose_hash the server reports.

3 App identity idle

Confirm the server's app_id matches the expected Lit Chipotle DstackApp address — the on-chain contract that governs its allowed configurations.

4 On-chain whitelist idle

Call allowedComposeHashes(bytes32) on the DstackApp contract on Base to confirm this exact configuration is whitelisted by the Lit Safe multisig.

5 Hardware quote & TLS-in-TEE idle

Full Intel DCAP quote validation and TLS-certificate pinning require introspection a browser cannot perform. Verify these with the Phala Trust Center, which checks all four properties automatically.
