lit-bridge

Permissionless cross-chain token bridge — verification by a Lit Action, not a validator set.

Service is up. The bridging UI is not built yet — this is the Phase 0 scaffold. The service is stateless; transfer state is read straight from chain.

Working endpoints:

  • GET /health — liveness
  • GET /api/config — registry chain + address (UI bootstrap)
