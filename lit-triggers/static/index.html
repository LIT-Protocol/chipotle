Scoped usage key safety

Your Lit/Chipotle admin API key is used only in this browser tab to mint a scoped usage key. It is never sent to lit-triggers, never stored, and is cleared after each mint attempt. The trigger stores only the scoped usage key needed to execute the action code identity (CID) with your group permissions.
